# 🎮 理數冒險王 (STEM Adventure Quest)

> **國一理化基礎 × 數學難度分級互動學習大挑戰**

「理數冒險王」是一款專為國中一年級學生設計的**跨領域 STEM 遊戲化學習平台**。將抽象的國一數學與理化觀念（如正負數、一元一次方程式、密度公式 $D=M/V$、聲音與光學）轉化為直觀、具吸引力的動態互動體驗。

## 💡 開發緣由與動機 (Motivation & Background)

### 📌 學習痛點發現

在國一學程中，學生首次面臨以下學習轉折與挑戰：

1. **概念抽象化**：數學從單純算術進入代數（一元一次方程式與等量公理），理化則需理解密度的導出公式與比例關係。

2. **缺乏即時反饋**：傳統紙本習題刷題枯燥，且答錯時無法立即得到步驟拆解與解題觀念。

3. **學習挫折累積**：弱點無法及時記錄與修復，導致隨學期推進漸漸失去理數學習興趣。

### 🎯 專案解決方案

本專案結合**遊戲化學習機制 (Gamification)** 與 **Web 動態視覺化技術**：

* 透過**闖關問答**與**詳細步驟解析**，即時導正觀念。

* 打造**互動實驗室**，讓學生透過拖動數值親眼觀察「密度沉浮」與「天平平衡」。

* 內建**錯題本系統**，自動收集答錯題目，實現精準弱點修復。

## ✨ 核心特色與功能模組 (Features & Modules)

### 1. 🎯 難度分級闖關問答 (Quiz Mode)

* **三階難度設計**：提供「🟢 簡單 (觀念基礎)」、「🟡 中等 (進階計算)」、「🔴 難 (高階素養)」三種模式。

* **多元題型支援**：包含多項選擇題 (MC)、觀念是非題 (TF) 及數值計算填空題 (Fill-in)。

* **即時解析系統**：答題後即時提供完整解題觀念與步驟拆解。

### 2. 🃏 觀念記憶卡牌 (Memory Matching)

* 將國一理數公式（如 $D=M/V$、絕對值定義、折射定律、等量公理）設計成卡牌對對碰。

* 透過翻牌遊戲強化名詞與定義之間的圖像化記憶連結。

### 3. ⚡ 60 秒限時大挑戰 (Time Attack)

* 60 秒倒數衝刺快問快答。

* 鍛鍊學生的計算反應速度與時間壓力下的解題熟練度。

### 4. 🧪 互動實境實驗室 (Interactive Concept Lab)

* **密度** $D=M/V$ **沉浮模擬器**：動態調整質量 ($M$) 與體積 ($V$)，燒杯中的物體會實時產生「浮起、懸浮、沉底」的物理效果。

* **一元一次方程式天平模擬器**：視覺化呈現 $x + A = B$ 的等量公理減法計算過程。

### 5. 📖 錯題檢視本 (Mistake Notebook)

* 系統自動收集作答錯誤之題目。

* 提供隨時檢視與單獨刪除複習功能，打造個人化弱點庫。

## 🛠️ 技術架構與亮點 (Tech Stack & Architecture)

* **前端介面**：HTML5, Tailwind CSS (單頁面響應式 RWD 設計)

* **視覺風格**：質感莫蘭迪色系 (Morandi Palette) 與流暢 CSS 卡牌翻轉動畫

* **音效系統**：Web Audio API (原生動態合成音效，免外部音訊檔)

* **特效與圖示**：Canvas Confetti (慶祝特效)、FontAwesome 6 Icons

* **設計模式**：單一檔案可執行架構 (Single-File Architecture)，零依賴性、輕量化、即開即玩。
